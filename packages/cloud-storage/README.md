# lombokclarion/cloud-storage

**S3 and GCS drivers for the Storage interface. Uses native curl — no vendor SDK dependency.**

> **[READ-ONLY]** Subtree split of [LombokClarion](https://github.com/codinglombok/LombokClarion). Contribute to the main repository.

## Install

```bash
composer require lombokclarion/cloud-storage
```
