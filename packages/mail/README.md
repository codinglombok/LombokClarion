# lombokclarion/mail

**Mail abstraction: Mailable value objects, SMTP/sendmail/log transports. No vendor SDK — a SES/Mailgun transport is one class implementing Transport.**

> **[READ-ONLY]** Subtree split of [LombokClarion](https://github.com/codinglombok/LombokClarion). Contribute to the main repository.

## Install

```bash
composer require lombokclarion/mail
```
