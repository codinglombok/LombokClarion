# lombokclarion/inertia

**Server-side adapter for Inertia.js SPA protocol. Render SPA page components from PHP controllers with shared data and version checking.**

> **[READ-ONLY]** Subtree split of [LombokClarion](https://github.com/codinglombok/LombokClarion). Contribute to the main repository.

## Install

```bash
composer require lombokclarion/inertia
```
