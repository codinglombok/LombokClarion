# lombokclarion/scheduler

**Cron-like task scheduler. Define recurring tasks in PHP, run with a single system cron entry pointing at `bin/lombokclarion schedule:run`.**

> **[READ-ONLY]** Subtree split of [LombokClarion](https://github.com/codinglombok/LombokClarion). Contribute to the main repository.

## Install

```bash
composer require lombokclarion/scheduler
```
