# lombokclarion/websocket

**WebSocket server abstractions: connection manager, rooms, auth integration. Bring your own event loop (Swoole, ReactPHP, Workerman).**

> **[READ-ONLY]** Subtree split of [LombokClarion](https://github.com/codinglombok/LombokClarion). Contribute to the main repository.

## Install

```bash
composer require lombokclarion/websocket
```
