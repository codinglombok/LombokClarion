# lombokclarion/notification

**Channel-based notifications: mail, database, log. Notifiable interface, explicit channel registration, queued dispatch via Bus.**

> **[READ-ONLY]** Subtree split of [LombokClarion](https://github.com/codinglombok/LombokClarion). Contribute to the main repository.

## Install

```bash
composer require lombokclarion/notification
```
